# Flashcards

Веб-сервис интерактивных карточек для изучения иностранных слов и грамматики:
формы слов, отделяемые приставки, примеры предложений, тренировка в режимах выбора ответа и письменного ввода.

> 🚧 В разработке. Текущий этап и задачи — на [Kanban-доске](https://github.com/users/dml-leto/projects/5)
> и в [milestones](https://github.com/dml-leto/Flashcards/milestones).

## Стек
- **Backend:** Kotlin, Spring Boot, PostgreSQL (JSONB), Flyway, Testcontainers
- **Frontend:** Vue 3, TypeScript, Vite, PrimeVue
- **Решения:** [docs/decisions](docs/decisions/README.md)
