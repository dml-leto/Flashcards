# **Функциональные фичи сервиса карточек (Спецификация MVP)**

В этом документе описан полный продуктовый функционал сервиса изучения иностранных языков и карточек. Описание выполнено с точки зрения конечного пользователя и бизнеса (без применения технических терминов). Для каждой фичи указан статус вхождения в MVP (Минимально жизнеспособный продукт).

## **1\. Аккаунты и разграничение доступа**

| Название фичи | Описание бизнес-функционала | Вхождение в MVP   |
| :---- | :---- | :---- |
| **Семейные аккаунты** | Поддержка 4 персональных аккаунтов (для каждого члена семьи). Каждый пользователь входит под своим логином и паролем, видит только свои папки, наборы карточек и личный прогресс. | **Входит полностью** |
| **Иерархия «Учитель — Ученик»** | Ролевая модель, где один аккаунт (Учителя/Родитель) может привязывать другие аккаунты (Учеников/Семьи), назначать задания \- обязательные наборы карточек для заучивания, просматривать отчеты об успеваемости и список наиболее ошибочных слов у учеников. | **Не входит (Post-MVP)** |

## **2\. Организация наборов и карточек**

| Название фичи | Описание бизнес-функционала | Вхождение в MVP   |
| :---- | :---- | :---- |
| **Папки и структурирование** | Создание, переименование, перемещение и удаление папок. Возможность объединять тематические наборы карточек по папкам (например, «Немецкий / Глаголы»). | **Входит полностью** |
| **Управление наборами (Decks)** | Создание и просмотр наборов карточек внутри папок, ручное добавление, редактирование и удаление отдельных карточек в наборе. | **Входит полностью** |

## **3\. Содержимое карточек (Rich Flashcards)**

| Название фичи | Описание бизнес-функционала | Вхождение в MVP   |
| :---- | :---- | :---- |
| **Двусторонняя карточка** | Базовые стороны: лицевая сторона (слово или конструкция) и обратная сторона (основной перевод). | **Входит полностью** |
| **Дополнительные грамматические поля** | Расширенные текстовые поля для карточки: примечания, примеры предложений с использованием слова, формы множественного числа существительных, формы прошедшего времени глаголов, отделяемые приставки. | **Входит не полностью (нужно решить про объем в MVP)** |
| **Дополнительные поля** | Любые текстовые аттрибуты, например: глагол/существительное/итп, цвет, итп | **Не входит  в MVP** |
| **Поиск карточек  по доп атрибутам** |  | **Не входит  в MVP** |
| **Медиа-файлы (Иллюстрации и Аудио)** | Возможность прикреплять картинки-иллюстрации к карточкам и озвучку/аудиофайлы с правильным произношением слова. | **Не входит (Post-MVP)** |
| **Готовые наборы слов** | Например 100 самых популярных глаголов на уровне А2, 100 самымх популярных слов для путешествия | **Не входит (Post-MVP)** |

## **4\. Процесс и режим обучения (Learning Engine)**

| Название фичи | Описание бизнес-функционала | Вхождение в MVP   |
| :---- | :---- | :---- |
| **Выбор направления заучивания** | При старте тренировки пользователь выбирает, что показывать первым: слово (лицевая сторона) или перевод (обратная сторона). | **Входит полностью** |
| **Режим выбора ответа (Multiple Choice)** | Показывается слово и 4 варианта перевода. После выбора ответа сразу открывается правильный вариант и показываются все доп. поля карточки (примеры, формы, приставки). | **Входит полностью** |
| **Адаптивная ротация батчами по 10 слов** | Учеба идет порциями по 10 слов. Если в порции были ошибки, эти слова переходят в следующий шаг тренировки, а остальные места заполняются новыми неизученными словами. | **Входит полностью** |
| **Режим письменного ввода (Writing Mode)** | После успешного прохождения карточек в режиме выбора вариантов (10–15 слов) включается этап письменной проверки: показывается перевод, а пользователь должен вручную набрать исходное слово. | **Входит полностью** |
| **Настройка количества вариантов и размера батча** | Возможность менять количество вариантов ответа (вместо 4 по умолчанию) и количество карточек в активной порции (вместо 10 по умолчанию). | **Входит частично (в MVP значения жестко зафиксированы: 4 варианта и 10 карточек)** |

## **5\. Импорт и загрузка наборов**

| Название фичи | Описание бизнес-функционала | Вхождение в MVP   |
| :---- | :---- | :---- |
| **Импорт словарей из файлов** | Возможность массово загружать наборы карточек из текстовых/табличных файлов единым файлом с сохранением всех доп. полей (приставок, примеров, форм). | **Входит полностью** |
| **Импорт архивов с иллюстрациями** | Загрузка ZIP-архива, содержащего словарь и папку с картинками/звуками для автоматической привязки медиа к карточкам. | **Не входит (Post-MVP)** |
| **Возможность назначить доп аттрибуты по словам** | Пользователь загружает слова , система сама заполняет доп аттрибуты на базе встроенных словарей | **Не входит (Post-MVP)** |
| **Автоматическое назначение картинок** | Пользователь загружает слова, отмечает в наборе проставить картинки автоматически, систам сама ищет картинки на карточки по словам. Пользователь просматривает назначенные картинки и либо утверждает выбор или не утверждает тогда картинка удаляется, до этого у картинки показывается иконка что она еще не утверждена | **Не входит (Post-MVP)** |

## **6\. Интеграция с ИИ и Telegram (AI / MCP Pipeline)**

| Название фичи | Описание бизнес-функционала | Вхождение в MVP   |
| :---- | :---- | :---- |
| **Авто-создание карточек по фото из книги** | Пользователь отправляет в Telegram-бот фотографию страницы из учебника или конспекта. Искусственный интеллект автоматически распознает слова, контекст, переводит их, выделяет приставки/формы и автоматически создает готовый набор карточек. | **Не входит (Post-MVP — Эпик CARD-4)** |
| **Интеграция с LLM-агентами через MCP Protocol** | Подключение внешних умных ассистентов (Claude, ChatGPT, Gemini CLI) напрямую к сервису карточек для выполнения голосовых/текстовых команд генерации. | **Не входит (Post-MVP — Эпик CARD-4)** |

## **7\. Статистика и интервальное повторение**

| Название фичи | Описание бизнес-функционала | Вхождение в MVP   |
| :---- | :---- | :---- |
| **Учет ошибок по карточке** | Подсчет количества верных и неверных ответов по каждому слову. Выделение наиболее "трудных" слов в наборе. | **Входит полностью** |
| **Алгоритм интервального повторения (SM-2) и графики** | Автоматический расчет оптимального дня для повторения слова (умный календарь повторений) и наглядные графики прогресса выученных слов за недели/месяцы. | **Входит частично (в MVP фиксируется статистика ошибок, а сам алгоритм SM-2 и дашборды перенесены в Post-MVP)** |
