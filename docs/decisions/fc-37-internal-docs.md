# FC-37 · Закрытая внутренняя документация

**Статус:** accepted · **Дата:** 2026-10-07

Короткие ADR отвечают только на «почему», а искать «как устроено сейчас» по закрытым issues после перерыва неудобно.
Нужен снимок текущего состояния с навигацией. Репозиторий проекта публичный, а подробную документацию пользователь
хочет держать закрытой, поэтому она ведётся в отдельном приватном репозитории. Публичные ADR остаются короткими.
Отвергнуты: GitHub Wiki (отдельный git без PR и ревью, быстро отстаёт), сайт на GitHub Pages (приватные Pages есть
только в Enterprise Cloud), папка внутри публичного репозитория в `.gitignore` или submodule (риск утечки,
ссылка на приватный репозиторий в публичном).
