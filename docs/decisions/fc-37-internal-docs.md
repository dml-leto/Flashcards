# FC-37 · Закрытая внутренняя документация

**Статус:** accepted · **Дата:** 2026-10-07

Короткие ADR отвечают только на «почему», а искать «как устроено сейчас» по закрытым issues после перерыва неудобно.
Нужен снимок текущего состояния с навигацией. Репозиторий проекта публичный, а спецификацию продукта, планы фич
и подробности устройства пользователь хочет держать закрытыми. Поэтому публичный `docs/` оставляем для пользователей
продукта (описания готовых фич, release notes) и коротких ADR, а всё внутреннее, включая бывший `docs/spec/`,
ведём в отдельном приватном репозитории. Задачи, milestones и доска остаются на GitHub. Удалённые файлы остаются
в истории git: секретов там нет, а переписывать историю `main` ради этого не стоит.
Отвергнуты: GitHub Wiki (отдельный git без PR и ревью, быстро отстаёт), сайт на GitHub Pages (приватные Pages есть
только в Enterprise Cloud), папка внутри публичного репозитория в `.gitignore` (риск случайно закоммитить)
и submodule (ломает checkout у всех, у кого нет доступа к приватному репозиторию).
