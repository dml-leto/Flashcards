# FC-2 · ADR: Фронтенд: Vue 3 + TypeScript + Vite + PrimeVue, SPA на том же origin

- **Статус:** Accepted
- **Дата:** 2026-09-26
- **Issue:** FC-2 ([#2](https://github.com/dml-leto/Flashcards/issues/2))

## Контекст
- Фронтенд целиком пишет Claude. Пользователь, backend-разработчик на Kotlin/Java, должен уметь вносить мелкие правки
  (тексты, поля форм, видимость элементов), не изучая фреймворк глубоко.
- Мобильного приложения не будет: UI должен быть адаптивным (mobile-first) и удобным на телефоне.
- Бэкенд и фронтенд живут в одном монорепо, код фронтенда не должен смешиваться с бэкенд-модулями.

## Решение
- **SPA** в каталоге `frontend/`: Vue 3 (Composition API, `<script setup lang="ts">`), TypeScript в strict-режиме, Vite.
- **UI:** PrimeVue (готовые адаптивные компоненты: формы, диалоги, тосты, меню). Раскладка: CSS flex/grid.
- **Данные:** TanStack Query for Vue для серверного состояния. Pinia только если появится общее клиентское состояние.
- **Контракт API:** типы и клиент генерируются из OpenAPI бэкенда (`openapi-typescript` + `openapi-fetch`).
  До готовности эндпоинтов используются моки MSW.
- **Тесты:** Vitest + Vue Testing Library, позже Playwright для e2e (Этап 8).
- **Адаптивность:** mobile-first вёрстка, PWA-манифест (установка на домашний экран), TTS через Web Speech API.
- **Раздача:** с того же origin, что и API. В dev через Vite proxy `/api` → `localhost:8080`, в prod через reverse proxy.
  CORS не нужен, cookie-сессия (FC-3) работает без `SameSite=None`.

## Рассмотренные альтернативы
- **React + Tailwind/shadcn:** крупнейшая экосистема, но модель хуков (`useEffect`, зависимости) и JSX хуже читаются
  без опыта во фронтенде.
- **Angular:** DI близок к Spring, но для 6–8 экранов избыточен по церемониям. RxJS — отдельная кривая обучения.
- **Kotlin/Wasm (Compose for Web):** один язык во всём проекте, но незрелость, canvas-рендеринг и проблемы
  с вводом и доступностью на мобильных.
- **Thymeleaf/htmx (SSR):** шаблоны оказались бы внутри Spring-модулей и смешали бы зоны ответственности.

## Последствия
- `.vue`-файл читается как HTML-шаблон + обычный TS: мелкие правки доступны пользователю. В `frontend/README.md`
  будет карта «где что лежит».
- Экосистема меньше React, но всё нужное для проекта (UI kit, query, тесты, PWA) зрелое.
- Фронтенд зависит от качества OpenAPI-спеки бэкенда. Неудобный контракт — повод для запроса на изменение API,
  а не для обходных решений на клиенте.
